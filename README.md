# 🍺 Bierpong

Bierpong in der Ich-Perspektive für Android – zu zweit per Bluetooth oder gegen den Computer.

## App herunterladen

**[👉 Neueste Version (Bierpong.apk)](https://github.com/Spiasm/bierpong/releases/latest/download/Bierpong.apk)**

## Spielen

- Ball unten antippen und schwungvoll nach oben wischen. Schneller = weiter, schräg = schräg.
- 10 Becher pro Seite, 2 Würfe pro Runde. Zwei Treffer = Bälle zurück.
- Zu zweit: Handys einmal per Bluetooth koppeln, einer tippt „Spiel erstellen“, der andere „Spiel beitreten“.
